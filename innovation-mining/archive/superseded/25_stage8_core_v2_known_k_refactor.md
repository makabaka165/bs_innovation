## Purpose

This stage isolates the continuous known-model-order fitting core from the
failed unknown-K diagnostic. It answers only whether known-K K1/K2 fits are
operational, whether a center-difference K2 parameterization removes target
exchange instability, and whether grouped initialization should be retained,
optional, or pruned relative to direct initialization.

The experiment is diagnostic-only. It does not define or evaluate an LRT,
threshold, false split, missed split, bootstrap state, six-state classifier,
or Stage8.2 decision.

Required report labels are:

- `KNOWN_K_DIAGNOSTIC_ONLY`
- `MODEL_ORDER_DEFERRED`
- `NO_FORMAL_THRESHOLD`
- `NO_STAGE8_1_VALIDATION_PASS`
- `NO_STAGE8_2_AUTHORIZATION`

## Frozen Boundary

The prototype is external to the frozen Stage8 implementation. It may call
existing Stage8 and R1 functions read-only, including the formal registry,
trial generator, initialization factory, fixed-grid fitter, sequential
manifold builder, concentrated DML scorer, source recovery helper, and K1
continuous refiner. It must not modify frozen Stage8 steps, calibration,
formal results, prior `23_*` or `24_*` evidence, archived prompts, or prior

The 0.2 degree grid remains a reproducible baseline and start generator. It
is not the final continuous parameter space. Grouped initialization is only a
candidate start generator until the paired known-K experiment decides its

## Shared Trial Contract

Each trial is regenerated by `stage8_r1_generate_trial`. Trial ID, seed,
truth, and element-trial hash must match the 24-row historical evidence in
`24_stage8_r1_continuous_refinement_decisive_trials.csv`. A mismatch makes
the experiment invalid.

Every element trial evaluates exactly three method rows from the same

rules, and scientific budget:

| ID | Known-K method |
|---|---|
| `B0_FIXED_GRID_KNOWN_K` | Frozen fixed-grid baseline |
| `B1_DIRECT_CONTINUOUS_KNOWN_K` | Direct/conventional starts plus continuous fitting |
| `B2_GROUPED_CONTINUOUS_KNOWN_K` | Grouped/conditional starts plus continuous fitting |

Only the truth K is evaluated. K2 trials may run a K1 helper solely to build
the registered embedded start; that helper is not a scientific output and is
never used for model-order inference. Truth may be used only after fitting for
target matching and error calculation. Truth starts, rescue starts,
method-specific budgets, and method-specific tolerances are prohibited.

## K1 Contract

K1 uses the frozen `stage8_r1_refine_continuous_dml` implementation with one
start. B1 starts at `conventional_singleton_peak_deg`; B2 starts at
`grouped_q1_kq1_angles_deg`.

A returned K1 estimate is valid when the start and estimate are finite, the
final manifold is full rank, RSS/sigma2/log-likelihood/score are finite, RSS
is nonnegative, and no monotonicity violation occurred. The normal converged
status is accepted. A max-sweeps result is accepted only for known-K angle
estimation when its final relative score change is at most `1e-7` and its
final angle update is at most `2e-3` degree; this is reported as
`K1_CONTINUOUS_MAX_SWEEPS_USABLE`.

## K2 Center-Difference Contract

For endpoints `theta1` and `theta2`, the optimizer uses

```text
theta1 = c - d/2
theta2 = c + d/2
c = [c_az, c_el]
d = [d_az, d_el]
```

The initial endpoints are sorted once by elevation then azimuth. The sign
convention is `d_el > 0`, or when `abs(d_el) <= 1e-12`, `d_az >= 0`. Endpoints
are never reordered inside coordinate updates. They are sorted only for
deterministic output and truth matching.

The common B1/B2 solver contract is:

| Parameter | Value |
|---|---:|
| max sweeps | 20 |
| scan points | 9 |
| center radius | 0.20 degree |
| delta-az radius | 0.40 degree |
| delta-el radius | 0.20 degree |
| `fminbnd` TolX | `1e-4` degree |
| `fminbnd` MaxFunEvals | 80 |
| relative score tolerance | `1e-8` |
| endpoint update tolerance | `1e-3` degree |
| usable relative tolerance | `1e-7` |
| usable endpoint tolerance | `2e-3` degree |
| minimum separation | `1e-3` degree |
| rank multiplier | 1 |
| update order | `c_az`, `c_el`, `d_az`, `d_el` |

All values enter the solver contract hash. Only `fminbnd` is permitted; no
Optimization Toolbox or third-party solver is used.

At each coordinate, global feasibility is intersected with the local radius.
Nine equally spaced nodes are scored. Score ties prefer the value nearest the
current value and then the lower numeric value. Neighboring scan nodes bracket
`fminbnd`. The current value, best node, refined candidate, and both bracket
endpoints are compared uniformly. An update is accepted only when the score
increase exceeds `64*eps(max(1,abs(current_score)))`; score decrease is never
accepted.

Feasibility requires both endpoints inside the local domain, separation at
least `1e-3` degree, effective rank two, and finite score. A sweep is
stationary when no update is accepted. It is converged when relative score
change is at most `1e-8` and maximum endpoint movement is at most `1e-3`
degree. At 20 sweeps it is usable only when there are no monotonicity
violations, each of the last three relative score changes is at most `1e-7`,
the final endpoint movement is at most `2e-3` degree, and the final fit is
finite and full rank. Other max-sweeps outcomes are not operational.

Valid starts are rebuilt and rescored through the full sequential manifold;
source coefficients are recovered and checked. The selected start maximizes
concentrated log-likelihood. Ties within
`64*eps(max(1,abs(max_loglik)))` preserve registered start order.

## Gates

G0 verifies the exploration branch and anchors, the `b606840` ancestor,
clean tracked history, frozen path integrity, and zero MATLAB/lock/coordinator
state for this runtime. Failure is a hard stop.

G1 uses only two fixtures: off-grid WHITE K1 with L=8 and SNR=+6, and EASY

angle and RSS `num2hex` values, selected start, and solver status must match.
Matching results select `TWO_WORKER_RESUMABLE`; otherwise the experiment uses
`ONE_WORKER_RESUMABLE` without investigating runtime metadata differences.

## Operational Decision

B1 and B2 are independently `KNOWN_K_CORE_OPERATIONAL` only when they have at
least 15/16 valid K1 fits, at least 7/8 valid K2 fits, off-grid K1 median joint
RMSE at most 0.05 degree, overall K2 median joint RMSE at most 0.20 degree,
zero monotonicity violations on every valid row, and zero truth leakage.

The grouped decision uses only the eight paired K2 trials and the exact
1e-3-degree win/loss tolerance from the active protocol. RETAIN, OPTIONAL,
and PRUNE use the protocol's operational, median-RMSE, win/loss, and mean
score-call conditions without modification.

The only final conclusions are:

- `STAGE8_CORE_V2_OPERATIONAL_GROUPED_RETAIN`
- `STAGE8_CORE_V2_OPERATIONAL_GROUPED_OPTIONAL`
- `STAGE8_CORE_V2_OPERATIONAL_GROUPED_PRUNE`
- `STAGE8_CORE_V2_K2_SOLVER_NOT_OPERATIONAL_STOP`
- `STAGE8_CORE_V2_EXPERIMENT_INVALID`

Completion does not authorize unknown-K LRT, bootstrap, a 6000-trial run, or
Stage8.2.
