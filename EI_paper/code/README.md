# 圆柱阵波束级最大似然测角演示代码

本文件夹用于存放 EI 小论文的仿真演示代码。当前主脚本为：

```matlab
run_cyl_beamspace_ml_demo.m
```

脚本特点：

- 不读取外部数据，不依赖工程源码函数；
- 从圆柱阵阵元坐标开始生成工作子阵；
- 构造阵元域目标观测 `Y=A_cyl(Theta)S+N`；
- 固定方位角，在俯仰向构造 `10` 个真实波束，形成 `W=[w_1,\ldots,w_10]`；
- 通过 `Z=W^H Y` 得到 `10 x L` 的波束域观测；
- 基于 `W^H W` 对 `Z` 和 `G(Theta)=W^H A_cyl(Theta)` 做波束域白化；
- 使用白化后的 `G(Theta)` 和 `J(Theta)=tr(P_G Z Z^H)` 完成波束级最大似然测角；
- 与波束扫描结果进行对比；
- 以 `0.1~1.0` 倍 3 dB 波束宽度设置十组目标俯仰间隔，其中 `0.5` 倍对应半个 3 dB 波束宽度场景。

当前脚本中有两个“10”，含义不同。第一个是波束数：固定方位 `az0`，俯仰向选取 `10` 个波束中心，因此 `W` 为 `M x 10`，`Z` 为 `10 x L`，`G(Theta)` 为 `10 x 2`。第二个是实验点数：仍以 `0.1~1.0` 倍 3 dB 波束宽度设置十组目标间隔，用于画结果图横轴。

由于这 `10` 个真实波束并非严格正交，原始波束域噪声协方差正比于 `W^H W`。脚本采用 `W^H W` 的逆平方根对白化后的观测和流形进行评分，即先得到 `Z_tilde=T W^H Y` 和 `G_tilde=T W^H A_cyl(Theta)`，再代入确定性最大似然准则。

运行方式：

```matlab
cd('E:\matlab_code\bishe_quanxi_papers\beamspace_ml_paper\12_EI\code')
run_cyl_beamspace_ml_demo
```

脚本不保存 CSV 结果文件，所有曲线均由本次仿真得到的内存变量直接绘制。运行后会在 `results` 文件夹下生成：

- `fig_single_case_half_bw.png`：半个 3 dB 波束宽度场景下的波束扫描结果和最大似然评分图；
- `fig_rmse_resolution_vs_separation.png`：十组目标间隔下的测角误差和分辨成功率对比图；
- `fig_snr_beam_comparison.png`：10、8、6、4、2 个俯仰波束在不同 SNR 下的测角误差和分辨成功率对比图；
- `fig_w_selection_score.png`：固定方位下不同目标间隔和不同波束数的波束选择诊断评分图；
- `fig_w_score_optimal_metrics_vs_B.png`：候选池内穷举搜索得到的评分最优 `W*_B` 随波束数变化的评分结果图；
- `fig_w_score_optimal_beam_layout.png`：评分最优 `W*_B` 对应的实际俯仰波束中心示意图。

`fig_single_case_half_bw.png` 的左图表示固定方位下的波束扫描结果，用于展示半个 3 dB 波束宽度目标场景下容易形成合并主峰；黑色虚线为真实目标位置，红叉为波束扫描结果给出的等效位置。右图表示在候选目标1/候选目标2俯仰角平面上的归一化最大似然评分。搜索不限定 `el_1` 与 `el_2` 的大小关系，因此评分图关于主对角线对称，两个黑色圆圈表示目标标签交换对应的两个等价真实位置，红色叉号为程序返回的一个 ML 最大值位置；主对角线的两个候选角度相同，不作为有效目标候选。

分辨成功率的判据分两步：首先，算法输出需要形成两个可区分的目标结果；其次，将两个估计俯仰角与两个真实俯仰角按从小到大配对后，两个目标的绝对误差均需小于 `0.1` 倍俯仰向 3 dB 波束宽度。该排序只用于目标标签不确定时的误差匹配，不参与最大似然搜索。

3 dB 波束宽度只在代码内部通过半功率点数值计算得到，用于设置目标间隔和图中标注，不再单独输出测量图。

当前代码只突出“固定方位、俯仰向局部目标分离”的主流程，便于和正文中的圆柱阵信号模型、波束域输入模型以及确定性最大似然评分公式对应。`beamspace_ml_pair_el_search` 对应的是固定方位下的俯仰成对搜索，即候选由 `(az0, el_1)` 和 `(az0, el_2)` 组成。搜索遍历 `i~=j` 的完整双向候选网格，不再使用上三角顺序约束。
