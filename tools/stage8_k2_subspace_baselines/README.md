# Retained FBSS Root-MUSIC Kernels

This directory supplies unchanged vertical covariance, reshape, FBSS covariance, Root-MUSIC and conditional azimuth CML kernels to the [two-scenario L8 experiment](../stage8_k2_raw_tangent_core_native_snr/README.md). Scientific default budgets are retained. GFBSS spectral MUSIC, LS-ESPRIT and legacy experiment registration/runners are removed.

Both SC_A and SC_B satisfy the distinct-elevation structural condition. A failed elevation or azimuth stage is an algorithmic failure in the full denominator. Historical entry points remain at parent f1b13422a91540073ecf417c3b25f5cac552b9d6.
