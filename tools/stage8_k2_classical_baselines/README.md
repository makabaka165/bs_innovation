# Retained Classical Kernels

This directory supplies unchanged Full4D CML, full element manifold, Beamspace MUSIC and peak-picker kernels to the [two-scenario L8 experiment](../stage8_k2_raw_tangent_core_native_snr/README.md). Scientific default budgets are retained; legacy experiment registration, result readers and runners are removed. The generic MUSIC kernel retains its dormant Element compatibility branch. No current runner calls Element MUSIC.
